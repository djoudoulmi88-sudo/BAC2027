# مِداد — فضاء دراسة السنة الثالثة ثانوي

موقع عربي متجاوب لطلاب السنة الثالثة ثانوي في الجزائر. لكل مادة صفحة مستقلة فيها محاورها، اختبار قصير، ومساحة لروابط المراجعة الخاصة بالطالب.

المواد: الرياضيات، الفيزياء، علوم الطبيعة والحياة، التربية الإسلامية، التاريخ والجغرافيا، العربية، الفرنسية، الفلسفة، والإنجليزية. المحاور مستندة إلى ملفات التدرجات السنوية المرفقة للعام 2022–2023.

## الخطط الشهرية

يحتوي الموقع على خطط أكتوبر إلى أفريل ضمن رزنامة موسم 2026–2027. تفتح كل خطة تلقائيًا في أول يوم من شهرها وتظل الخطط السابقة متاحة. ملفات PDF المرفقة في `site/plans` هي نسخ الملفات التي أرسلها المستخدم؛ عناوين معظمها تشير إلى BAC 2025، بينما خطة أكتوبر تشير إلى BAC 2027.

## دروس وتمارين BAC STORY

تحتوي بطاقات محاور المواد على روابط مباشرة إلى ملخصات وتمارين BAC STORY ذات الصلة، مع رابط إضافي لمواضيع المادة واختباراتها. تبقى صفحات BAC STORY هي مصدر ملفات الدروس والاختبارات؛ ويحتوي الموقع على اختبار قصير تفاعلي مستقل لكل مادة.

## تشغيل الموقع محليًا

يتطلب اتصالًا بالإنترنت لتحميل مكتبة Supabase من CDN والخطوط. من مجلد المشروع شغّل خادم ملفات ثابت، مثل:

```sh
python -m http.server 8000 --directory site
```

ثم افتح `http://localhost:8000`.

## إعداد Supabase

1. أنشئ مشروع Supabase.
2. من SQL Editor شغّل الملف `supabase/setup.sql` لإنشاء جدول روابط الدراسة وسياسات RLS.
3. في `site/src/supabaseConfig.js` ضع رابط المشروع ومفتاح `publishable` العام.
4. تأكد من تفعيل البريد وكلمة المرور في إعدادات Auth. أضف عنوان الموقع المحلي وعنوان GitHub Pages إلى عناوين إعادة التوجيه المسموح بها.
5. تأكد أن جدول `study_resources` متاح عبر Data API؛ قد تتطلب المشاريع الجديدة إظهاره صراحة في إعدادات Data API.

بعد الإعداد، ينشئ الطالب حسابًا أو يسجل الدخول، وتُحفظ روابطه في حسابه وتظهر له وحده. قبل الإعداد يعمل الموقع بوضع محلي ويحفظ الروابط في المتصفح الحالي.

مفتاح `publishable` مخصص للواجهة العامة. لا تضع مفتاح `service_role` أو مفتاحًا سريًا في ملفات الموقع أو في GitHub. الوصول إلى السجلات محكوم بسياسات RLS في قاعدة البيانات.

## النشر على GitHub Pages

المستودع يتضمن سير عمل GitHub Actions لنشر مجلد `site` تلقائيًا عند الدفع إلى الفرع `main`.

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. اختر **Settings → Pages → Build and deployment → GitHub Actions**.
3. انتظر انتهاء سير العمل، ثم استخدم عنوان الموقع الذي يعرضه GitHub Pages.
4. أضف عنوان الموقع إلى إعدادات Supabase Auth ضمن عناوين إعادة التوجيه.

لا يلزم إعداد بيئة بناء أو تثبيت حزم npm للنشر.
